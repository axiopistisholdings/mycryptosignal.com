Frequently Asked Questions

How do I get an API key? Visit the Get API Key page and fill out the request form. Keys are typically issued within 24-48 hours.
Is the API really free? Yes. The API is free with attribution required. See Terms of Service for attribution requirements.
What are the rate limits? Rate limits vary by API key tier and may change without notice. Check the API Documentation for current limits.
Can I use signals commercially? Yes, with proper attribution. You may NOT resell or redistribute signals as a standalone product. See Terms of Service for details.
Are signals guaranteed accurate? NO. Signals are informational only and NOT financial advice. Read the full Risk Disclaimer before using.
Can I contribute to the project? Yes. Check the GitHub repository and submit pull requests for bug fixes or improvements.
